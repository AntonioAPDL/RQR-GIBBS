# Oracle-tilt illustration evidence (version 2)

This directory contains compact, hashed evidence for the single-data 95% fixed-design and dynamic-linear interval-root illustrations.
The illustrative innovations follow an affinely standardized asymmetric-Laplace law with source index 0.80.
Ordinary RQR, equal-tailed, and shortest-interval tilts are computed from the exact population law; no Cornish--Fisher approximation is used.
The dynamic construction uses a fixed physical horizon and the exact continuous-time local-linear transition covariance at each grid step.
These artifacts summarize loss-based generalized posteriors; they do not define a response likelihood or posterior-predictive response law.
