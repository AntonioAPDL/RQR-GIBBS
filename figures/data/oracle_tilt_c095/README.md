# Oracle-tilt illustration evidence

This directory contains compact, hashed evidence for the single-data 95% fixed-design and dynamic-linear interval-root illustrations.
The three columns of each figure target ordinary RQR, the equal-tailed oracle tilt, and the shortest-interval oracle tilt.
The tilts are computed from the known standardized asymmetric-Laplace innovation law; no Cornish--Fisher approximation is used.
These artifacts summarize loss-based generalized posteriors and do not define or evaluate a posterior-predictive response distribution.
