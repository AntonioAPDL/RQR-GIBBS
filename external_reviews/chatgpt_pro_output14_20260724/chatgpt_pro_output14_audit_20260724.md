## 4. Preliminary simulation: mathematical target and oracle

### 4.1 Location-scale equivariance

Let

\[
Y_t=\mu_t+s_t Z_t,\qquad s_t>0,
\]

and choose candidate roots \(L_t=\mu_t+s_t a\) and
\(U_t=\mu_t+s_t b\). Then

\[
(Y_t-L_t)(Y_t-U_t)=s_t^2(Z_t-a)(Z_t-b).
\]

Because the check loss is positively homogeneous,

\[
\rho_c\{s_t^2 e\}=s_t^2\rho_c(e),
\]

so the conditional population risk for \(Y_t\) is \(s_t^2\) times the
standardized risk for \(Z\). A global minimizer \((a_c,b_c)\), \(a_c<b_c\),
therefore maps exactly to

\[
L_{t,c}=\mu_t+s_ta_c,\qquad U_{t,c}=\mu_t+s_tb_c.
\]

The finite-second-moment requirement is appropriate because the residual
product is quadratic in \(Z\). Centering and variance standardization do not
alter the argument. A positive floor for every generated \(s_t\) and a
predeclared minimum root separation are still required in the DGP validator.

### 4.2 Stationary equations are not a global certificate

For a continuous law and an interior ordered stationary point, the two
first-order conditions imply

\[
P(a_c<Z<b_c)=c,\qquad
E\{Z\,1(a_c<Z<b_c)\}=cE(Z).
\]

They do not establish existence, uniqueness, or global optimality. The draft
recognizes this correctly. Multiple starts, tighter numerical integration, an
independent solver, objective comparison, and a nonunique-root fallback are
necessary, but a positive local Hessian alone is not a global certificate.

Before implementation, add an independent one-dimensional profile check. For a
continuous CDF \(F\), parameterize all coverage-\(c\) intervals by

\[
a(u)=F^{-1}(u),\qquad b(u)=F^{-1}(u+c),
\qquad 0\le u\le1-c.
\]

Evaluate the population RQR objective on an adaptively refined grid in \(u\),
then bracket and optimize every candidate basin. Compare the resulting global
minimum with the unrestricted two-dimensional solver and stationarity
equations. For unbounded support, use probability coordinates and explicit
tail-error bounds. Record:

```text
distribution and parameter digest
coverage and moment residuals
2-D solver objective
1-D profile objective
endpoint order and separation
local curvature
global-minimum gap
uniqueness / minimizer-set status
quadrature error bound
```

If several minima are indistinguishable within the numerical error bound,
endpoint RMSE is not defined against one selected pair. Use excess population
RQR risk and distance to the minimizer set instead.

## 5. Aims, DGPs, and identifiability

The six stated aims are useful, but the preliminary six-core mechanism matrix
does not fully isolate all of them.

### 5.1 Controls that should be retained

The static Gaussian and local-level Gaussian mechanisms are not redundant.
The first is a negative control for an asymmetry advantage; the second tests
the value of dynamic roots when RQR and equal-tailed endpoints coincide. Keep
both.

The local-level log-normal mechanism is the cleanest direct-root asymmetry
contrast and should remain core.

The unequal-evolution trend-regression mechanism is appropriate for testing
component-specific state evolution, provided a common-evolution ablation is
added and all root/quantile methods receive the same component design.

### 5.2 Required matched multicomponent control

The trend-seasonal skewed mechanism simultaneously changes component
structure, time-varying scale, and asymmetry. It cannot by itself identify
whether a gain is due to multicomponent dynamics, scale adaptation, or the RQR
endpoint target.

Add a matched **trend-seasonal Gaussian** core control with the same
\(\mu_t\), \(s_t\), state variances, seasonal period, horizons, and seeds as
the skewed mechanism. This creates a two-by-two interpretation:

```text
multicomponent dynamics, symmetric errors
multicomponent dynamics, asymmetric errors
```

Alternatively, downgrade the trend-seasonal claim to a composite mechanism.
The matched control is preferable because the stated aims explicitly separate
dynamics from asymmetry.

### 5.3 Component-specific evolution ablation

Add a predeclared common-scale or common-discount RQR-DLM ablation for the
unequal trend-regression mechanism. The true-\(W\) oracle is noncompetitive and
does not replace this ablation. Without it, the study cannot attribute a
difference to component-specific rather than generic dynamic evolution.

### 5.4 Stress and sensitivity mechanisms

The structural-break heavy-tail mechanism deliberately combines an abrupt
break, skewness, and heavy tails. It is valid as a stress test but cannot
support separate claims about break robustness or heavy-tail robustness.
Retain the composite label and avoid mechanism-specific causal language. Split
it only if one of those effects becomes a primary claim.

For the independent-root alignment sensitivity, generate ordered root paths
with a strict separation floor. Given standardized oracle roots \(a_c<b_c\),
map ordered paths \(L_t<U_t\) to

\[
s_t=(U_t-L_t)/(b_c-a_c),\qquad
\mu_t=(b_cL_t-a_cU_t)/(b_c-a_c),
\]

and then generate \(Y_t=\mu_t+s_tZ_t\). This is the needed response-generating
contract. A pair of root paths alone does not define a response law. For a
study that evaluates both 0.80 and 0.90 coverage on the same replication,
recover \((\mu_t,s_t)\) once from one declared reference coverage and derive
the roots at every other coverage from that same response law; do not generate
a different response process for each coverage.

Every provisional variance, break location/magnitude, seasonal amplitude,
scale floor, predictor law, initial state, and future-state rule must move from
prose into a versioned machine-readable DGP table before the diagnostic pilot.
The pilot may reject degenerate/trivial mechanisms using predeclared DGP-only
criteria, but it may not tune these values using comparative method
performance.

## 6. Estimands and performance measures

### 6.1 Keep method targets distinct

Population RQR roots and equal-tailed quantiles are different estimands under
asymmetry. The current draft stores both truths, but the performance section
must specify target alignment explicitly:

- RQR methods: endpoint error relative to population RQR roots;
- quantile methods: endpoint error relative to the corresponding population
  quantiles;
- all methods: common operating measures such as held-out RQR loss, empirical
  coverage, width, failure, and computation;
- optional cross-target endpoint distance: label it as distance to the RQR
  target, not estimator bias for a quantile method.

Do not rank a correctly estimated equal-tailed endpoint as a failed estimate
of an RQR root. A paired quantile comparator is intentionally a different
decision rule.

Held-out RQR loss is a legitimate primary measure for the RQR scientific
target, but it is a home-target score. The manuscript must pair it with
coverage-width displays and the secondary central interval score rather than
present it as target-neutral superiority.

### 6.2 Replace the coverage-width rule

The proposed rule

\[
|\widehat C-c|\le0.01+1.96\,MCSE(\widehat C)
\]

is not an equivalence test. A noisier estimate receives a wider admissible
region, so uncertainty can make a method more likely to qualify.

Use this contract instead:

1. Predeclare a practical coverage-equivalence margin
   \(\Delta_C=0.02\) for the main 0.80 and 0.90 analyses.
2. For each method/cell/horizon, form the replication-level coverage estimate
   and its Monte Carlo standard error.
3. Declare the method coverage-qualified only when a 90% two-one-sided-test
   confidence interval for \(\widehat C-c\) lies wholly inside
   \([-\Delta_C,\Delta_C]\).
4. Make a narrower-width claim only when both compared methods are
   coverage-qualified and the paired width-difference interval supports the
   direction.
5. Always show the coverage-width frontier, including nonqualified methods.

The 0.02 margin is compatible with the proposed replication cap. At exact
nominal coverage, a 90% interval requires approximately 1,083 replications for
\(c=0.80\) and 609 for \(c=0.90\). A 0.01 margin would require approximately
4,330 and 2,436 replications, respectively, and is therefore incompatible with
the 2,500 cap for the 0.80 cells. If the scientific team insists on a 0.01
margin, increase the cap before confirmatory seeds are opened.

Coverage-standardized width obtained by post hoc test-set adjustment is not an
acceptable replacement. A predeclared training/calibration-only rate grid may
be used to estimate a coverage-width frontier, but test responses cannot tune
the interval.

### 6.3 Central interval score

The central interval score remains useful as a secondary proper score for the
equal-tailed interval functional. It is not neutral among all intervals with
the same coverage, so it should not replace held-out RQR loss for the direct
RQR target. RQR still has no response log-score or CRPS contract.

## 7. Methods, comparators, and tuning

### 7.1 Dynamic quantile comparator

A paired dynamic quantile comparator is necessary and should remain core.
CRAN `exdqlm` 1.1.0 is a suitable implementation candidate only under this
frozen contract:

```text

```

The official CRAN update record reports version 1.1.0 on 2026-07-09. Do not
rely on the package name or a mutable CRAN URL at run time; cache and attest
the exact source tarball. The comparator must not silently use exAL skewness
learning, LDVB, or a different state design.

Fit the lower and upper quantiles separately at \((1-c)/2\) and
\((1+c)/2\). Store raw crossing rates. For interval scoring, use an explicitly
declared ordering rule and disclose that ordering changes the pair of raw
quantile estimates.

The static quantile comparator must also be frozen as one specific method.
The current “frequentist or separately validated Bayesian” wording is not a
configuration.

### 7.2 Conformal methods

Ordinary split CQR is not admissible for these dependent mechanisms without an
exchangeability argument. EnbPI provides approximate marginal coverage under
strong-mixing stochastic-error and estimator conditions; local-level
nonstationarity and an abrupt structural break do not automatically satisfy
those assumptions. Weighted conformal methods beyond exchangeability provide
coverage-gap bounds, not assumption-free exact coverage under arbitrary drift.

Therefore, conformal prediction should be omitted from the first diagnostic
pilot or retained as a sensitivity on a predeclared subset of mechanisms for
which its assumptions and tuning protocol are verified. It should not be a
core baseline and cannot be described as automatically valid.

### 7.3 Tuning fairness

The preliminary discount grid is a reasonable candidate grid, but the rule is
not frozen. Before implementation specify:

- the exact training/validation split or rolling-origin folds;
- whether discounts are common or component-specific;
- the maximum number of evaluated combinations per method;
- the native training-only criterion for each target;
- deterministic tie breaking;
- failure handling; and
- whether selected discounts are refit on the full training window.

Use equal computational-search budgets. Tuning RQR methods by validation RQR
loss and quantile methods by validation check loss is defensible because the
targets differ, but it must be stated as target-specific tuning rather than a
common objective. Report a fixed literature-standard discount sensitivity to
show that conclusions are not driven by a larger grid.

The fixed generalized-Bayes rate of one after training-only response
standardization is a convention, not a calibrated constant. Keep rates
0.5, 1, and 2 and normalized learned lambda as sensitivities; never select a
rate by test coverage.

## 8. Replications and Monte Carlo precision

The replication is correctly identified as the independent Monte Carlo unit.
Within-replication horizons must remain clustered in pooled summaries.

For a Bernoulli coverage estimator, the worst relevant per-horizon Monte Carlo
standard errors are

\[
MCSE(\widehat C)=\sqrt{\widehat C(1-\widehat C)/R}.
\]

At nominal coverage, an MCSE target of 0.01 requires about 1,600 replications
for \(c=0.80\) and 900 for \(c=0.90\). Thus the 500 start, 250 batches, and
2,500 cap are proportionate. The 25-replication pilot has coverage MCSE about
0.08 at 0.80 and 0.06 at 0.90 and cannot support performance conclusions; the
draft already says it is only for mechanics and variance planning.

Clarify the pilot unit. “Four-chain diagnostic pilot on every core cell” should
mean a predeclared set of datasets in each mechanism-by-coverage cell, not four
chains for all 25 pilot replications. Use at least two preselected diagnostic
replications per cell for each MCMC method, with four chains each, and use the
remaining pilot replications for single-chain runtime/failure and
Monte-Carlo-variance planning after the schedule is frozen.

The “2% of oracle width or training scale” rule is ambiguous. Freeze separate
denominators:

```text
endpoint and midpoint error:
  MCSE <= 0.02 * training-response SD

mean width and paired width difference:
  MCSE <= 0.02 * mean oracle RQR width

held-out RQR loss and paired loss difference:
  a separately predeclared standardized-loss MCSE target
```

If the oracle width is near zero, stop the DGP as degenerate rather than
silently switching denominators.

Stopping may depend only on these predeclared precision criteria and the
replication cap, never on rank, sign, significance, or favorable results.

## 9. MCMC within the simulation

The bounded result justifies a computationally economical confirmatory design,
but one chain without any per-fit diagnostic is insufficient.

The preliminary compromise is acceptable after these clarifications:

- the diagnostic pilot uses four dispersed chains on at least two preselected
  replications per core cell and MCMC method;
- the final schedule is chosen from the worst predeclared diagnostic summaries,
  not from performance;
- each confirmatory fit uses one chain with a minimum within-chain bulk ESS,
  tail ESS for predeclared scalar functionals, finite-state, zero-repair, and
  exact-provenance checks;
- four-chain sentinels are selected by seed before data generation and
  stratified by mechanism, coverage, method, and replication batch;
- the 5% sentinel rate is applied within each stratum, with at least two
  sentinels per 250-replication batch when the percentage would yield fewer;
- a sentinel failure is reported and triggers the predeclared cell-level stop
  rule; it does not cause reseeding or outcome-driven extension; and
- failed fits remain in the intention-to-run denominator.

The diagnostic pilot must estimate the actual T=200/H=20 runtime and memory
budget. The bounded T=24--36 timing is not sufficient to authorize the
confirmatory grid.

## 10. Forecast interpretation and exact counterexample

The point interval formed from posterior means of ordered future root functions
is a well-defined frequentist procedure. Across independently generated
training/future paths, its empirical response coverage is a meaningful
operating characteristic. It is not posterior-predictive coverage and it does
not provide a response distribution.

The current oracle-recovery language conflates two future objects:

1. the realized future population root path after future state innovations;
2. the conditional-mean root forecast given the information at the forecast
   origin.

An exact counterexample is a local-level lower root

\[
L_{T+1}=L_T+\epsilon_{T+1},\qquad E(\epsilon_{T+1})=0,\quad
Var(\epsilon_{T+1})=q>0.
\]

A perfect conditional-mean forecaster reports \(L_T\), yet its RMSE against the
realized root \(L_{T+1}\) is \(\sqrt q\), not zero. Calling that error failure
to recover the population root confounds estimation with irreducible state
innovation.

Store and evaluate both:

```text
realized_root_path:
  operating outcome after generated future innovations

oracle_conditional_mean_root:
  E(root_{T+h} | information available at T, DGP parameters)
```

Use the conditional-mean oracle for forecast-estimand bias/RMSE and the
realized path for realized forecast error. The true-W method provides a useful
state-forecast benchmark but remains noncompetitive. Coverage continues to use
the generated future response and the method's point interval.
