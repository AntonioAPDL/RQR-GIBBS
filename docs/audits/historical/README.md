# Historical validation artifacts

Files in this directory are retained only to preserve the audit trail. They
are not current validation contracts.

`output6_independent_references_uncorrected_cdf.csv` contains six valid
independent posterior-mean references and five event-probability values that
were later found to use insufficient quadrature boundary splitting. The five
CDF rows are superseded by
`application/inst/extdata/output7_corrected_cdf_references.csv`. The six valid
mean rows are published separately, without the superseded CDF rows, in
`application/inst/extdata/ordinary_v1_f01_independent_mean_references.csv`.
