## Correction

For a content-(c) probability window with endpoints (a=Q(u)) and
(b=Q(u+c)), the fixed response-scale tilt is

\[
\delta(u)
=
\frac{1}{c}\int_a^b y\,dF(y)-E(Y).
\]

The historical V1--V4 illustration helper stored the unnormalized truncated
first moment instead. That convention is numerically equal to the correct
tilt only in special cases. The Gibbs kernels already accepted a correctly
scaled fixed tilt; the defect was in the illustration-oracle input, not in the
static or dynamic Gaussian conditional update.

The new package certificate uses schema
`rqrgibbs_interval_oracle/2.0.0` and records
`tilt_definition=conditional_retained_mean_minus_population_mean`. It also
records analytic and numerical checks, target and solver metadata, and
content-addressed digests. Cornish--Fisher approximations are prohibited in
this exact-DGP correction.

For standardized asymmetric-Laplace innovations with source index 0.80 and
content 0.95, the certified tilts are:

| Target | Lower-tail index | Exact tilt |
|---|---:|---:|
| RQR | 0.012080802865419 | 0 |
| ET | 0.025 | 0.0560608464325982 |
| SH | 0.04 | 0.1147218630644100 |

The decimal values in execution artifacts must be generated by the package
certificate rather than copied from this table.
